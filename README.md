# HR Management Pro

نظام إدارة الموارد البشرية متكامل يعمل محلياً داخل المتصفح باستخدام HTML/CSS/JavaScript.

## مميزات النظام
- لوح تحكم إحصائية
- إدارة الموظفين
- تسجيل الحضور والغياب
- إدارة السحوبات
- حسابات الرواتب والمعاملات
- تقارير شهرية
- إدارة المشتركين الخاصين
- إعدادات الشركة
- نسخ احتياطية واستعادة

## التشغيل
1. افتح ملف `index.html` مباشرة في المتصفح.
2. أو استخدم خادم محلي بسيط مثل:
   ```bash
   python -m http.server 8000
   ```
3. افتح الرابط التالي في المتصفح:
   ```bash
   http://localhost:8000
   ```

## ملاحظات
- جميع البيانات محفوظة محلياً عبر `localStorage`.
- يمكنك إنشاء نسخة احتياطية من البيانات واستعادتها في أي وقت.
- النظام جاهز للتطوير والتخصيص لاحقاً.
